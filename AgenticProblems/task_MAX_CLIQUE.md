# Problem Statement
Write an Answer Set Programming (ASP) program that models the Maximal Clique problem by translating the natural-language rules below into ASP rules.
Given an undirected graph, find the largest subset of vertices in an undirected graph where every vertex is connected by an edge to every other vertex in that subset.


## Natural-Language Rules
- There is an edge between two nodes whenever there is another edge in the reverse direction.
- Guess the nodes for the clique.
- Any two different nodes in the clique have to be connected by an edge.
- The number of nodes in the clique have to be the maximum possible.
