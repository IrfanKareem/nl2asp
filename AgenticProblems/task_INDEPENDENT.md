# Problem Statement
Write an Answer Set Programming (ASP) program that models the Maximum Independent Set problem by translating the natural-language rules below into ASP rules.
The Maximum Independent Set Problem consists in finding the maximum set of vertices where **no** two vertices are connected by an edge.
The program **maximizes** the number of vertices in the independent set.

## Natural-Language Rules
- All vertices can be in the independent set.
- Two selected vertices in the independent set cannot be connected by an edge
- Maximize the number of vertices in the independent set.
